# 📦 Smart Dashboard UI Kit - Package Contents

Esta carpeta contiene el paquete completo y desacoplado del Sistema de Diseño **Smart Control Panel / Dashboard UI Kit** listo para ser exportado y llevado a otros proyectos.

## 📂 Archivos en el Paquete

1. **`smart-dashboard-ds.css`**: Hoja de estilos del Sistema de Diseño desacoplado (Tokens CSS, variables, componentes y sistema de grilla).
2. **`styles.css`**: Copia del CSS original del proyecto.
3. **`app.js`**: Copia del script de JavaScript (filtros de stack, navegación de pestañas, simulador de terminal y telemetría de usuario).
4. **`demo.html`**: Showcase interactivo en vivo con todos los componentes renderizados.
5. **`STYLE_GUIDE.md`**: Guía de estilo detallada con código HTML y documentación de componentes.

## 🚀 Cómo exportar a otros proyectos

Simplemente copia la carpeta `smart-dashboard-ui-kit` o importa directamente `smart-dashboard-ds.css` y `app.js` en tu nueva aplicación web.
